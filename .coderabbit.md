# CodeRabbit AI Instructions

## Project Context
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS 4.0
- **Icons**: Lucide React
- **API**: OpenWeatherMap

## Mandatory Rules
1. **Navigation**: Always use `next/link` for internal routing. Never use `<a>` tags.
2. **Components**:
   - UI components must reside in the root `/components` folder.
   - Use Client Components (`"use client"`) only when necessary (hooks, events).
3. **Images**:
   - All external images must use `next/image`.
   - Ensure `remotePatterns` in `next.config.ts` matches the image source.
4. **Performance**:
   - Use Server Components for data fetching in `page.tsx`.
   - Implement proper loading states using `loading.tsx` or Suspense.
5. **Security**:
   - Never commit `.env` files.
   - API keys must be accessed via `process.env`.
